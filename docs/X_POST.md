**zec-request**: make shielded Zcash payments easy to request.

• Generate ZIP-321 payment links + QR with amount, label & encrypted memo
• Multi-recipient requests
• Decodes Unified Addresses (ZIP-316, own BLAKE2b + F4Jumble): see every receiver and whether it is shielded or PUBLIC
• Shareable payer page + one-line "Pay with ZEC" embed button
• English + हिन्दी
• Blocks memos to transparent addresses (a silent failure elsewhere)
• Zero dependencies, runs 100% locally, MIT
